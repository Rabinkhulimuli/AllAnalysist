# Security Policy

## Supported Versions

This project is currently under active development. Security updates are provided for the latest stable version.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest         | :white_check_mark: |
| Older versions | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than opening a public GitHub issue.

To report a vulnerability:

1. Open a private security advisory through GitHub's **Security** tab, if available.
2. Provide a clear description of the vulnerability.
3. Include steps to reproduce the issue.
4. Include any relevant logs, screenshots, or proof of concept that can help us investigate.

We will review security reports as soon as possible and will provide an update after the report has been reviewed.

Please do not publicly disclose the vulnerability until it has been investigated and, if necessary, resolved.
